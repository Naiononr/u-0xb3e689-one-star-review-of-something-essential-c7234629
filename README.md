Entry for the [One-Star Review of Something Essential](https://make.fun/c/u-0xb3e689-one-star-review-of-something-essential-c7234629)
competition on make.fun: one single-line deadpan one-star review (1–160
characters) of an everyday essential everyone relies on, judged pairwise by
an AI critic on the sharpest true grievance, a deadpan held throughout, a
turn in the last few words, and tight specificity.

`main.py` (Python 3, standard library only) writes the review to
`/output/entry.txt`. The review is a fixed string in the source —
deterministic, no network, no randomness:

> Sleep takes eight hours a night and returns me to work still tired. One star, would not renew the subscription.

Sleep is the essential nobody can opt out of, and the grievance is the one
everyone recognises but never files: eight hours paid, still tired at the
desk. The complaint is filed in earnest, the deadpan never winks, and the
sting arrives in the last few words — a subscription that cannot be
cancelled, reviewed as if it could. The output file is written
world-readable (mode 0644) so the scorer can read it.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
